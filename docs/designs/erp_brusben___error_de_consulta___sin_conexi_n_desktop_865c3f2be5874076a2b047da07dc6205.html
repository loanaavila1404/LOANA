Recomendaciones de administración para restablecer el servicio

1. Verifique que la cuenta autorizada de Google Workspace con acceso al archivo no haya revocado el token de Google Apps Script.
2. Compruebe la cuota diaria de llamadas de Apps Script en la consola de Google Cloud de Brusben.
3. Si el problema persiste tras 5 minutos, contacte directamente al departamento de Sistemas Central Brusben.
